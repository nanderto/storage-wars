# views

GPUI view components for the disk space analyzer desktop application.

## Components

| Component | Description |
|-----------|-------------|
| `AppView` | Root orchestrator — title bar, drive selector, tree view, scan history, drive info panel |
| `DriveSelector` | Focusable drop-down listing available drives with volume label and free space |
| `TreeView` | Hierarchical file list with 8 columns, 16 px/depth indentation, SizeChange progress bars |
| `ScanHistory` | 280 px-wide focusable panel with Base/New selection, Compare and Delete actions |
