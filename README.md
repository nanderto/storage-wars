# Storage Wars

A desktop storage management application built with [GPUI](https://github.com/zed-industries/zed/tree/main/crates/gpui) — the GPU-accelerated UI framework from Zed Industries.

## Features

- 1280 × 800 window, centered on primary display
- Dark theme with amber accent palette
- Custom transparent title bar
- Modular sub-view architecture

## Prerequisites

| Dependency | Version |
|---|---|
| Rust | stable (≥ 1.80) |
| macOS | 12+ (Monterey) **or** Linux (X11/Wayland) |
| Xcode CLT | macOS only |
| `libxcb`, `libxkbcommon` | Linux only |
