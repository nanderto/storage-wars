# Storage Wars

A desktop application built with **Rust** and **GPUI** (the GPU-accelerated UI framework from Zed).

## Requirements

| Tool | Version |
|------|---------|
| Rust | stable (see `rust-toolchain.toml`) |
| macOS | 12+ *or* Linux (X11/Wayland) *or* Windows 10+ |
